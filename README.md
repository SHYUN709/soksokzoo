# 속마음 동물원

> 내 안에 사는 동물은 누구일까?
> 30개 상황(약 3분)에서 더 나다운 쪽을 고르면 나를 닮은 동물 캐릭터와 찰떡 궁합, 살짝 안 맞는 궁합을 알려주는 자기이해 테스트.

**테스트 하러 가기 → https://soksokzoo.vercel.app/**

---

## 이런 걸 알려줘

- **내 캐릭터**: 동물 5마리 × 아이템 5개 = 25가지 캐릭터 중 하나 (예: "취향 확실한 비버")
- **이런 사람이야**: 성향 설명, 강점, 조심할 점
- **동물 궁합**: 찰떡 궁합 동물과 살짝 안 맞는 동물
- **기준 궁합**: 삶의 기준이 잘 맞는 사람과 엇갈리는 사람
- **상세 마음 지도**: 10개 축 점수를 오각형 차트 2장으로
- **인스타 스토리 카드**: 1080×1920 결과 이미지 저장·공유

## 캐릭터 구성

**나는 어떤 사람? (성향 1위 → 동물)**

| 동물 | 성향 | 한 줄 |
|---|---|---|
| 다람쥐 | 현실감 | 모아두고 대비하는 현실 만렙 |
| 고양이 | 감수성 | 분위기를 제일 먼저 읽는 섬세함 |
| 리트리버 | 친화력 | 어디서든 분위기 메이커 |
| 올빼미 | 이상추구 | 생각이 많은 밤의 몽상가 |
| 비버 | 추진력 | 맡으면 끝까지, 일 처리 장인 |

**나의 기준 (기준 1위 → 수식어 + 아이템)**

| 기준 | 수식어 | 아이템 |
|---|---|---|
| 관계 | 곁을 챙기는 | 빨간 목도리 |
| 신뢰 | 약속은 꼭 지키는 | 금빛 배지 |
| 체계 | 계획대로 움직이는 | 체크리스트 클립보드 |
| 주관 | 내 갈 길 가는 | 선글라스 |
| 취향 | 취향 확실한 | 베레모 |

## 점수는 이렇게 계산해

- **빠른 검사 30문항** (기본, 약 3분): 상황형 양자택일. 같은 그룹의 두 축을 맞붙이고, 축마다 정확히 6번씩 등장
  - 둘 다 괜찮은 선택지라 "좋아 보이는 답"으로 쏠리는 현상이 적어
  - 점수 = 그 축이 선택된 비율, 동점이면 맞대결 결과 → 응답 기반 해시 순으로 결정 (특정 동물 편애 없음)
- **정밀 검사 40문항** (선택, 약 8분): 상황형 4지선다. 상황마다 다섯 축 선택지 중 한 축씩 돌아가며 빼고 4개를 보여줘
  - 그룹당 20문항, 축마다 정확히 16번 등장하고 A~D 자리에도 4번씩 고르게 배치
  - 점수 = 보여진 횟수 중 그 축을 고른 비율, 동점 처리는 빠른 검사와 같아
- 표시 점수는 아무렇게나 골랐을 때의 비율(양자택일 50%, 4지선다 25%)을 50점으로 맞춘 0~100점이야. 4지선다는 그 축이 나왔을 때 60% 이상 고르면 100점
- 성향 1위가 동물, 기준 1위가 수식어가 돼
- 무작위 응답 2만 번 시뮬레이션에서 두 검사 모두 다섯 동물이 각각 약 20%씩 나오는 것을 확인
- 성향 점수 차가 20점 미만이면 "상황마다 다른 동물이 나오는 타입"으로 따로 안내

## 기술

- HTML · CSS · JavaScript 파일 하나 (`index.html`), 빌드 과정 없음
- 캐릭터는 SVG로 직접 그림, 스토리 카드는 Canvas로 생성
- 응답은 브라우저(localStorage)에만 저장하고, 서버로 보내지 않아
- 배포: Vercel (GitHub `main`에 push하면 자동 배포)

## 로컬에서 실행

```bash
cd psychological-test

```
